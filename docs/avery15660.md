# Avery 15660 Label Sheet

The `public/avery15660.html` page lets a user enter up to five shared lines and
print them across selected labels on an Avery 15660 sheet.

## Layout

- Letter-size sheet: 8.5" × 11"
- Label size: 2.625" × 1"
- Layout: 3 columns × 10 rows (30 labels)
- All labels are selected by default

## Controls

- Five optional line inputs in the sidebar
- Row, column, and individual label selection
- Select All / Clear All
- Print Labels opens the browser print dialog

Deselected labels print blank. Printing uses 0.1875" left and 0.5" top margins,
with a 0.125" horizontal gap between labels.

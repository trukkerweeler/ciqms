# Avery 5395 Name Badge Sheet

The `public/avery05395.html` page lets a user enter up to five shared lines in
the sidebar and print them across selected labels on an Avery 5395 sheet
(adhesive name badges).

## Layout

- Letter-size sheet: 8.5" × 11"
- Label size: 3.375" × 2.333" (3⅜" × 2⅓")
- Layout: 2 columns × 4 rows (8 labels)
- All labels are selected by default

## Controls

- Five optional line inputs (each with a Bold toggle) in the sidebar
- Font size selector (12–36 pt, default 18 pt)
- Row, column, and individual label selection
- Select All / Clear All
- Print Labels opens the browser print dialog

Deselected labels print blank. Printing uses 0.78125" left and 0.75" top
margins with a 0.1875" horizontal gap and no vertical gap. If a printer shifts
the output, adjust `--left-margin` / `--top-margin` in the page CSS and the
matching values in the print window styles in `buildPrintWindow`.
